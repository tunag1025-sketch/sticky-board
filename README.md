# 실시간 메모 보드

강연·토크콘서트용. 관객이 휴대폰으로 메모를 쓰면 무대 화면에 포스트잇처럼 바로 붙습니다.

| 주소 | 용도 |
|---|---|
| `/` | 관객 메모 작성 (QR로 접속) |
| `/board` | 무대 화면 (최신순 격자, 스크롤로 전체 열람) |
| `/admin` | 관리자: 메모 삭제(5초 안에 되돌리기), 접수 마감/재개, 검색, 전체 삭제, 접속자 수 |

## 실행
```bash
npm install
ADMIN_PASSWORD=원하는비번 npm start
```

## 환경변수
| 이름 | 기본값 | 설명 |
|---|---|---|
| `ADMIN_PASSWORD` | `admin1234` | 관리자 비밀번호 (**꼭 변경**) |
| `PUBLIC_URL` | 접속 주소 | QR 코드에 넣을 주소 (예: `https://memo.example.com`) |
| `MAX_LEN` | `100` | 메모 최대 글자 수 |
| `COOLDOWN_MS` | `3000` | 한 사람이 연속으로 보낼 수 있는 간격(ms) |
| `PORT` | `3000` | 포트 |
| `BANNED_WORDS` | (없음) | 금칙어 추가, 쉼표로 구분 (예: `단어1,단어2`) |
| `FILTER` | 켜짐 | `off`로 두면 금칙어 필터 끔 |

## 금칙어 필터
욕설은 저장 전에 `***`로 가려집니다. `시 1 발`처럼 글자 사이에 공백·숫자·기호를 넣어 피하는 것도 잡아요.
"새끼 고양이" 같은 오탐을 막으려고 일상어와 겹치는 단어는 기본 목록에서 뺐습니다. 필요하면 `BANNED_WORDS`로 추가하세요.

## 디자인
- 완전 흰 배경, 폰트는 Pretendard(SIL OFL)로 통일. 폰트는 npm 패키지에서 서버가 직접 서빙하므로 외부 CDN이 막혀도 동작합니다.
- 색·간격·모션 값은 `public/common.css`의 토큰으로 관리합니다.
- 접근성: 입력 라벨, 키보드 포커스 링, 44px 이상 터치 영역, 스크린리더 알림, '동작 줄이기' 설정 존중.

## 보드 화면 옵션 (URL)
- `/board?title=오늘의 토크콘서트` — 상단 제목 변경
- `/board?size=280` — 메모 크기(px), 클수록 한 줄에 적게
- `/board?qr=0` — QR 숨김

## 데이터
메모는 `data/notes.json`에 저장되어 서버를 재시작해도 남습니다(최대 3000개).
Render 등 클라우드에서는 재배포 시 파일이 초기화될 수 있으니, 행사 중엔 재배포하지 마세요.

## 부하 테스트

```bash
N=150 ROUNDS=3 npm run loadtest
```
